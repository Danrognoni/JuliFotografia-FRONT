# Directorio de Fuentes Personalizadas

Este directorio contiene la estructura para las dos fuentes corporativas y editoriales del proyecto:

## 1. `FK Roman Standard` (Florian Karsten)
Ubicación: `public/fonts/fk-roman-standard/`
Uso: Títulos (`h1` a `h6`), encabezados de galerías, displays y acentos editoriales.

Archivos esperados:
- `FKRomanStandard-Regular.woff2` (o `.woff` / `.ttf`)
- `FKRomanStandard-Italic.woff2` (o `.woff` / `.ttf`)
- `FKRomanStandard-Bold.woff2` (o `.woff` / `.ttf`)

Fuente de respaldo (Fallback): `Playfair Display`, `Georgia`, `serif`.

---

## 2. `Studio Pro` (Multi Form)
Ubicación: `public/fonts/studio-pro/`
Uso: Cuerpo de texto (`p`), botones, links de navegación (navbar), captions, inputs y etiquetas de UI.

Archivos esperados:
- `StudioPro-Regular.woff2` (o `.woff` / `.ttf`)
- `StudioPro-Medium.woff2` (o `.woff` / `.ttf`)
- `StudioPro-Bold.woff2` (o `.woff` / `.ttf`)

Fuente de respaldo (Fallback): `Inter`, `Helvetica Neue`, `system-ui`, `sans-serif`.
